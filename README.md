# KT_38_EvenNumbers

# Вариант 1. Чётные числа с трассировкой
1) Метод IEnumerable<int> EvenNumbersUpTo(int max) с yield return внутри цикла.
2) Добавьте Console.WriteLine перед каждым yield return, обозначающий, что готовится конкретное значение.
3) Создайте переменную, вызвав метод, но не перебирая её — продемонстрируйте, что трассировка ещё не появилась.
4) Переберите результат через foreach, выводя полученное значение, и продемонстрируйте, что строки трассировки и «получено» чередуются по одному.
5) Дополнительно продемонстрируйте EvenNumbersUpTo(...).Take(2) — и убедитесь, что трассировка появляется только для первых двух значений, а не для всех.

# Ограничения
Реализация обязана использовать именно yield return внутри метода, возвращающего IEnumerable<T> — не материализацию всей последовательности в List<T> с последующим возвратом.
